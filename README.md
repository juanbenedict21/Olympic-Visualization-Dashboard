# Olympic-Visualization-Dashboard

An interactive Olympic dashboard created to analyze and visualize Olympic data using Tableau.
This project focuses on transforming Olympic data into an interactive dashboard that presents key insights through various charts and visualizations.
The dashboard allows users to explore Olympic-related data and identify patterns and insights through an interactive visual interface.
